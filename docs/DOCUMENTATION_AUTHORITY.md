# Aetherwake Documentation Authority

**Reconciled:** 2026-09-21  
**Scope:** active pre-alpha development

This document is the routing layer for Aetherwake documentation. It exists to prevent historical prototype notes from being mistaken for current design or runtime truth.

## Authority order

1. **Executable truth:** supported entrypoints and the files they actually load. See `docs/RUNTIME_AUTHORITY.md`.
2. **Current technical target:** `SPEC.md`, `docs/JRPG_COMBAT_DIRECTION.md`, and current automated contracts.
3. **Visual target:** `docs/ART_DIRECTION.md` plus canonical character dossiers in Notion.
4. **Creator canon / unresolved design:** Aetherwake Notion Narrative & Canon workspace.
5. **Historical provenance:** preservation-era notes, old concept trees, `gap_analysis.md`, non-runtime mirrors, and superseded checkpoints.

Historical documents remain useful evidence. They must not be read as current implementation merely because their text still exists.

## Current high-level state

- Five canonical playable protagonists: **Ender, Lyra, Ionia, Reson, Aepex**.
- Exactly three active combatants are the production target.
- Ender is **22** and his canonical native job is **Rift Scholar**.
- Lyra is **24**; her exact native job and formal magic-school classification remain unresolved.
- Ionia is **28**, captain/owner of the ship, and an experienced navigator/caretaker; she is not an elderly farmer.
- Reson is **25**, a burly former-service weapon master using rifle/pike/sword vocabulary.
- Aepex is **27**, a machinery/computation/invention specialist.
- Production combat direction is conventional formula-driven JRPG combat. Preservation-era 2D6/PbtA material is compatibility/history, not the production design.
- The active art direction is modern pixel-art JRPG: authored geography, richer sprites/animation, restrained modern lighting/effects, solarpunk/aether-tech materials, and character art grounded in the Notion dossiers.
- Open-sky navigation is a distinct exploration domain with altitude, landmarks, routes, weather zones, docking, and turn-based random sky encounters routed through the shared combat framework.
- The current visual-development branch includes coherent biome composition, geographic shorelines, pixel atmosphere, the Unfinished Song exterior/interior visual language, and flight presentation.

## Ship naming

Documentation currently contains both **Aureate Wake** and **The Unfinished Song**.

Treat this as a **canon reconciliation item**, not permission to silently replace one name everywhere. Older character/narrative records consistently use *Aureate Wake*; current art/development work uses *The Unfinished Song*. Until creator canon explicitly resolves whether these are an old name, formal name, nickname, class/lineage distinction, or replacement, both names must retain provenance.

## Open design that must remain open

Do not infer canon for:
- Lyra/Ionia/Reson/Aepex magical ownership unless explicitly established;
- Lyra/Ionia/Aepex exact native job;
- Ionia’s final weapon/combat style;
- Aepex’s exact weapon/tool loadout;
- a single iconic Reson weapon (rifle, pike, and sword are all established proficiencies);
- exact protagonist hair/eye colors, ethnicity, or costume details unless later creator canon establishes them;
- final ship naming reconciliation.

## Documentation maintenance rule

When a milestone materially changes runtime, canon, or art direction:
1. update the relevant authoritative document;
2. add a dated reconciliation note to the Notion Operational Control Center;
3. leave historical records intact but label superseded target claims;
4. never “clean up” uncertainty by turning it into invented canon.
