## 1. Real integrated path

Existing native cubed-sphere tile planner/mesh and *mode-5 actual geodesic camera* → native `worldmap_cartography.gd` → weather-aware read-only `worldmap_material_context.gd` → optional `worldmap_surface_material_preview.gd` → **exactly one selected currently active tile** using original `godot/shaders/planetary_surface_study.gdshader`. The original `StandardMaterial3D` remains default for all active terrain.

`J` in mode 5 cycles **OFF → SNOW LOOK → SYNTHETIC RAIN-WET LOOK → OFF**. The surface review is a **cosmetic study, not in-game weather**. Only an actually eligible visible tile receives a new material; otherwise the header says **NO ELIGIBLE TILE** and no tile material changes. It selects the nearest eligible current active tile and reuses the shader resource across unchanged refreshes. Ocean, ship/marker, sun, sky, mode 4, main scene and existing WorldEnvironment ownership are untouched.

The in-memory toggle is **excluded from `snapshot()` and the existing save schema**, reset when applying a loaded snapshot, rejects unknown materials and works only when `_mode=="tiles"`. Low quality suppresses the effect and restores the original material. The selected tile key always belongs to `active_keys()`, and no new physical collider, displacement, landing permission, chart discovery, story or route unlock is created. The source tile count/cached mesh budgets remain **32/64**, with the original native planner unchanged. Current tile mesh LOD is uniform in any one plan, not mixed-LOD geomorphing.

## 3. Visual QA — do not call this a finished biome

Actual in-flight photographs confirm real rendered change but reveal **large smooth blocks of uniform color, sharp triangular tile outlines and visibly discordant material changes at one-tile boundaries**, especially wet-ground darkening. The initial detached shader before #514 also exhibited bad periodic diagonal striping and was revised; these world-scene captures do not erase that rejection history.

The selected native tiles are real spherical geometry, but the current 12-division source mesh and placeholder biome fixture are visibly low-detail; the camera faces a broad, feature-poor near-horizon surface rather than a cinematic landscape. The original globe obscuring/coverage and uniform-LOD limitations remain, and no real snowfall/rain, weather accumulation, collision, landscape vegetation, target-GPU performance or asset approval is demonstrated. **Art acceptance: HOLD.** Do not boost pixel delta by exaggerating one tile's brightness, gloss or darkening.

## 4. Next production tests, in order

1. **Continuity first:** native neighbors must receive compatible material-family blending where actual source biomes cross tile edges; prove zero world-space position cracks plus independent normal/material transition QA. Avoid hard one-tile look discontinuities and aliased seams. Define first legitimate shared biome samples from a single authoritative native `Cart.sample`; do not blend across physical ocean/land/collider authority.
2. **Native runtime quality control:** add explicit `high/low` and reduced-motion decisions to world-map renderer settings (not just low-quality test injection), with frame-by-frame camera movement and quality-toggle screenshots; test tile stream cache churn and switch back under active steering.
3. **Actual playable globe composition:** address missing/flat coverage outside planned tile addresses, near-horizon gaps, geometric continuity across different LOD levels, physically grounded lighting and forest/snow/shore materials; connect water and atmosphere to one weather owner.
4. **Physical surface authority:** create collision-backed terrain *only* from accepted height data and verify real Godot multi-contact raycasts, safe landing-state transitions and support-loss; `land` or a material family never grants permission.
5. **Independent art and device gates:** creator palette approval/Visual Bible, representative high-quality original textures, real Windows GPU/VRAM/Forward+ and lower-end hardware budgets, cold-shader compile/stream stalls, accessibility and flight-camera motion. Preserve strict Defender custody gate. No production or canon promotion without explicit owner approval.
