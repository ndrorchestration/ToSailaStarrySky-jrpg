# Flight-lab regional materials and coastline wetness — visual contract

**Candidate / noncanonical / draft-only.** Stacks on texture study PR #445, visual transition PR #420, and environmental-mood PR #417. The branch changes the isolated 960×640 Godot 4.7.2 *Compatibility flight scene*, not the complete globe or Chapter One playable builds.

## Scope
- Fourth **real, committed 128×128 RGBA PNG**, `godot/flight_slice/textures/biome_macrodetail.png`, generated byte-for-byte by the existing offline original texture generator `tools/generate_surface_textures.mjs`; GitHub CI runs `node ... --check` to audit all **four** texture assets. This mask has three independently seeded slow-varying channels.
- Terrain shader samples the large-format regional art mask at a **different world-space frequency** (0.018 per world unit) from the 0.24-unit fine texture. It modulates pasture, alpine rock and beach color **within** existing height/slope-based boundaries. No new height generator, biome map gameplay, collision surface or tree placement.
- Ocean and terrain share the exact authoritative `TerrainStudy.SEA_LEVEL` parameter. Near sea level, sand is selectively darker/less rough; the existing water depth/coverage shoreline foam acquires subdued, regional patchiness from the same PNG. There is no alternate bathymetry, hidden coast collision, or water navigation zone.
- `J` toggles the **regional biome and wet shoreline layer**, and `K` independently controls existing microtexture grain. `V` suppresses both. `M` still suppresses rain/vegetation movement; no new animation or flashing light is introduced.
- The existing visual weather transitions, physics-confirmed touchdowns, cinematic camera, Five Lights narrative energy/job separation, Moon Bridge secrecy, and world time are unaffected.

## Verification and review gates
1. `node godot/flight_slice/tools/generate_surface_textures.mjs --check` proves exact repeatable PNG bytes of all four textures, rather than merely confirming file presence.
2. `tests/test_surface_textures.gd` and `tests/test_biome_layers.gd` require native Godot PNG import, real material bindings, J/K/V independence, shared sea level, and unchanged clock/ship/terrain/rain instance budgets.
3. `tests/capture_biome_macro.gd` outputs **six real 960×640 OpenGL frames**, matched per pose and time in three coast/forest/storm-night A/B pairs with only J changing. Pixel deltas assert visible integration; they **do not** certify cinematic taste, target GPU performance, biological plausibility or material identity.
4. Existing landing, camera, atmosphere, rendered-flight and repository smoke gates must pass at the exact commit.
5. Pending: actual target GPU timings, thin coastal edges, motion/shimmer at variable altitude, a fully art-directed forest floor, high-resolution final textures and user acceptance. The coastline approximation is height-based and may affect noncoastal lowland sand; this should not ship without a real coastline-distance field. Do **not** merge or release without creator approval.

**Creative scope:** These colors and original art masks are a temporary technical study, not new planet canon, not a named new biome and not a moon/auroral navigation clue.
