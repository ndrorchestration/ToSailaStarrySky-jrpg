The landforms, colors, 6371-km reference radius, high-altitude ceiling, simulation time compression, and speed controls are test fixtures only. Tile payloads are generated into a bounded in-memory cache, not fetched from disk/network. This is not a GPU terrain engine, actual 3D rendering, or an integrated game build. Prototype work remains separate from First Wake and the save system.
