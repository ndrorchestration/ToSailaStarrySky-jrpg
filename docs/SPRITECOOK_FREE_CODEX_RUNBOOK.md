## Monthly free-credit strategy
- **40 free / 30 days**, non-rolling; **8–12 credits per detailed image** depending on selected model; animations typically **20–26** and would crowd out the first usable HUD art. The account's actual current balance may be lower. Source: https://www.spritecook.ai/pricing
- **First:** one 8–12-credit Detailed render, *not* a generic 9-item pixel-art pack. TSTSS is moving toward cinematic 3D; crisp painted HUD/prop art aligns better than cheap-looking replacement character sprites.
- **Optional, only after native inspection:** a **24-credit / 9-asset Mini Pack** is available on Free but is **pixel-art only**, and may conflict with our cinematic style; use it only if a suitable, clearly identified real consumer exists. Source: https://www.spritecook.ai/game-asset-pack-generator . Otherwise bank remaining credits for one or two additional targeted Detailed icons. Do not assume free credits carry to next month.
- Use the first approved SpriteCook **asset ID as a style reference** for later generations where supported, without uploading protected character reference images to SpriteCook's **public free gallery**.
- Free downloads include PNG and ZIP; **special Godot/Unity packages, full packs, private generations and 2K/4K** are paid. Do **not** subscribe. Godot imports PNG files automatically. Source: https://www.spritecook.ai/pricing and https://docs.godotengine.org/en/4.7/tutorials/assets_pipeline/importing_images.html

## Direct Godot import path (no paid SpriteCook engine export)
1. Keep the approved asset under the real project's `godot/assets/.../spritecook-candidates/` or a nearby clearly provisional location (do not copy the main-branch legacy `assets/` into Godot blindly).
2. Godot automatically imports the PNG as a texture. Use `TextureRect` for HUD art, `Sprite2D` for a field prop, or a material texture only where a true 3D receiver exists. **Do not change global texture filtering** to pixel-art/Nearest for a Detailed painted asset or the whole cinematic game; set per-control/per-node filtering based on review.
3. An icon can be tested in a separate opt-in scene. Review actual HUD overlap, safe margins, legibility at 960×640, lighting integration and texture artifacts. Only after creator approval should it replace a live-game placeholder.
4. Run documented native import/scene tests, then record exact Godot binary, branch and SHA and real screen captures. Do not report a preview render as an approved game integration.

Never use a paid automation service to bypass the free-tier limit. The browser plug-in sign-in path is preferred because it needs **no API key**. See https://www.spritecook.ai/agents and https://www.spritecook.ai/api-docs . If neither an authenticated Codex connection nor a secure MCP client is available, generate nothing until one is.
