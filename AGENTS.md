# Aetherwake Codex Repository Instructions
Read current gameplay, narrative and visual source-of-truth files, release documentation, and repository tests before modifying this game.
- Artistic goal: visually convincing anime-inspired modern Star Ocean-style solarpunk JRPG; visual quality is a separate acceptance gate from functional smoke tests.
- Preserve established character portraits/sprite consistency and join order, crew accord, airship shielding story, and auroral-lane gating until the authorized story source changes.
- Verify affected browser interactions, save/replay paths, visual captures, Windows packaging and launch behavior as appropriate to the change.
- Distinguish evidence CAPTURED, UPLOADED/PUBLISHED, HUMAN_REVIEWED, and VISUAL_PASS. CI success never substitutes for actual appearance review.
- When artifact quota or retention blocks publication, preserve capture contract and document exactly which evidence remains unavailable.
- Avoid unrelated broad gameplay, art and CI rewrites in narrow release-tooling fixes; report changed files and exact candidate head.
- Do not announce a playable, visually approved, downloadable release without the relevant validated artifact and link.
